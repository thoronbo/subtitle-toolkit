# 字幕工坊 Subtitle Toolkit

打开就能用的字幕处理工具。不用安装，不用联网，字幕内容不会离开你的设备。

## 能做什么

**格式互转**　SRT、WebVTT、ASS 三种格式随意转换，时间轴精确到毫秒。

**时间轴校准**　整体提前或延后；也可以按帧率换算，把整条时间轴等比例拉长或压缩。

**双语合并**　放入第二份字幕，会按时间自动配对，一句原文配一句译文，顺序可切换。

**整理**　合并相邻的重复字幕，收紧互相重叠的时间，限制每屏最多显示几行。

**质检**　统计条数、总时长、最长空档，并标出语速过快、观众来不及看完的句子。

## 打开方式

双击 `index.html` 即可使用。字幕可以粘贴进输入框，也可以直接把文件拖进页面。

想先看效果，可以拖入 `examples/demo.srt`，里面特意放了重叠、重复和语速过快的句子。

支持的格式：

| 格式 | 读取 | 导出 |
| --- | --- | --- |
| SRT | 支持 | 支持 |
| WebVTT | 支持 | 支持 |
| ASS / SSA | 支持 | 支持 |

## 使用中的几个细节

- 文件编码会自动识别，UTF-8、UTF-16、GBK 都能正常读取。
- 时间轴的改动实时生效，结果区随时可以复制或下载。
- 时间轴上偏黄的片段代表语速偏快，可以照着警告逐条调整。
- 调整顺序是「先按倍率缩放，再整体偏移」，偏移量永远对应最终的播放画面。
